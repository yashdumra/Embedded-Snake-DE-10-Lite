# Demonstration media

This directory is reserved for real captures of the DE10-Lite Snake demonstration.

Media prepared from the author's November 2026 recording:
- `snake-start.jpg` — early game
- `snake-gameplay.jpg` — extended snake in the obstacle course
- `snake-game-over.jpg` — collision / loss state
- `snake-demo-highlights.mp4` — short highlight video of the monitor

The footage was captured from a physical lab monitor, not digitally recreated or simulated. Video and image files will be added separately.

After the files are uploaded, the main README can embed screenshots using relative links such as `assets/snake-gameplay.jpg`.
